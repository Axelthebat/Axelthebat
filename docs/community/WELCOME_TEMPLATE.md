## Welcome

This is the discussion board for my open-source work: security tooling, Linux and networking, and cloud infrastructure.

### Choosing a category

| Category | Use it for |
|---|---|
| Q&A | Questions about a tool, a stack, or a security concept |
| Ideas | Feature requests and design proposals |
| Show and tell | Your own labs, tools, and write-ups |
| General | Everything else |
| Announcements | Releases and project news |

### Before you post

1. Search first. Many questions are already answered in an existing thread.
2. Redact secrets. Do not paste real tokens, credentials, private keys, customer data, or production IPs. Use placeholders such as `192.0.2.10` or `ghp_XXXX`.
3. Report vulnerabilities privately through [SECURITY.md](https://github.com/Axelthebat/Axelthebat/blob/main/SECURITY.md). Do not open a public issue or discussion for a vulnerability.
4. File bugs as issues using the templates, so I can reproduce them.
5. Keep it respectful. This is a small space.

### What to include

For questions about a specific tool, include:

- Your OS and version (`uname -a`, `cat /etc/os-release`)
- The tool version (`--version`)
- The exact command and the complete error output
- What you have already tried
